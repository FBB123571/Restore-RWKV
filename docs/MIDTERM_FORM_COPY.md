## 二、项目进展状况小结（复制下面整段）

```
本项目面向边缘端实时去雾需求，以 Restore-RWKV 线性复杂度视觉主干为基础，中期围绕「轻量化基线构建—文献方向验证—可插拔消融—工程化开源」四条主线推进，整体进度符合任务书安排。

（一）数据与基线方面：已完成约 1.4 万对 hazy/clear 数据整理与配对，采用 128×128 分辨率、MSE 损失训练 Vision-RWKV V1 基线（hidden_dim=32，num_blocks=2，参数量约 0.028M），训练 50 epoch 收敛，主观去雾清晰、色彩自然，具备边缘端轻量化优势。

（二）改进与消融方面：针对任务书提出的多方向探索目标，项目组设计四条轻量插件路线——A 频域混合（FourierMix2D）、B 双域高频精炼、C 深度门控、D 空间残差精炼，并引入 V1 锚定损失与有界 scale 机制，保证训练稳定。已完成 A/B/C/D 模板试训（512 张、3 epoch）与 B/C/D 全量训练（15 epoch），建立 validate、preview、metrics 一体化评测流程。

（三）实验结果方面：在统一 hold-out 集上，V1 基线 PSNR 20.66 / SSIM 0.827；插件 A、C 与 V1 数值最接近（ΔPSNR 分别为 −0.04、−0.52），主观样例整体可接受；B、D 在部分难例上 hold-out 指标偏低，已定位原因并列入后续 epoch 扫描计划。曾尝试 256 整网重训（V2），因灰图与对比度塌缩问题终止，确认「冻结基线 + 插件」为中期主技术路线。

（四）团队与文档方面：项目负责人刘小凡统筹实验与代码仓库，成员杨媛迪、汪静怡、郭嘉恒分工参与文献整理、训练调试、对比图制作与报告撰写；指导教师金枝定期指导技术路线与汇报材料。中期报告、Markdown 详版与 PDF 已整理完毕并上传 GitHub。

综上，项目已完成任务书规定的基线构建、文献调研、消融框架、训练评测与中期汇报等核心节点，为后期边缘端部署优化与多模态扩展奠定基础。
```

## 三、项目存在问题及解决方案、项目下一步计划（复制下面整段）

```
【存在问题】

1. 插件整体尚未显著超越 V1 基线：在强锚定约束与较小 scale 设定下，A/C 与 V1 接近，B/D 在 hold-out 集上 PSNR 偏低，说明轻量改动对难例（浓雾、低对比）提升有限。

2. 训练 epoch 与 checkpoint 选择不够精细：B/D 全量训练采用 epoch_14，可能存在过拟合，导致客观指标与主观观感不完全一致。

3. 测试覆盖不足：当前主观展示以 5 张典型图为主，缺少浓雾、夜间等非均匀雾况子集，难以全面反映边缘端鲁棒性。

4. 「多模态大模型」与边缘端部署仍处前期：中期以 Vision-RWKV 去雾基线与插件消融为主，文本/语义引导模块与端侧推理加速尚未完全落地。

【解决方案】

1. 针对单方向插件分别调整 scale 上限与锚定权重，在验证集上早停，避免破坏 V1 稳定性的同时释放改进空间。

2. 对 B/D 开展 epoch 5/10/14 扫描，选取验证集最优 checkpoint；构建浓雾难例子集，联合 PSNR、SSIM 与主观评分评价。

3. 保持「不改动原 V1 模型」原则，继续采用可插拔消融范式，确保对比公平、结果可回退。

4. 在现有开源仓库基础上补充推理脚本与部署说明，为后续 Jetson/移动端 INT8 量化与多模态文本先验接入预留接口。

【下一步计划】

2026 年 6 月：完成 B/D 最优 epoch 评选与难例集评测，更新指标表与对比图；整理插件权重 GitHub Release。

2026 年 7 月：制作论文级六列 montage 与消融汇总表，完善答辩 PPT 素材；探索轻量文本描述引导的去雾增强模块（多模态方向）。

2026 年 8 月：开展边缘端推理测速与模型压缩试验，形成「精度—速度—参数量」三联对比；完善使用文档。

2026 年 9 月：撰写大创结题报告，汇总全部实验数据、开源链接与成果清单，完成结题答辩准备。
```
