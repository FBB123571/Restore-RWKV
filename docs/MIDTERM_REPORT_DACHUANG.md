## 一、研究背景与意义

### 1.1 研究背景

图像去雾是计算机视觉与智能感知的基础问题，在自动驾驶、安防监控、遥感测绘及医学影像预处理等领域具有广泛应用。传统基于物理散射模型（如暗通道先验 DCP、大气散射模型 ASM）的方法依赖手工特征，在浓雾、非均匀雾、夜间场景下鲁棒性不足。深度学习方法虽显著提升去雾质量，但多数 CNN/Transformer 结构计算量大，难以在边缘设备实时部署。

Restore-RWKV（IEEE JBHI, 2026）将 RWKV 线性注意力引入医学图像复原，具备 **O(n) 复杂度** 与长程依赖建模能力。本课题在其思想基础上，面向 **自然图像去雾** 构建 Vision-RWKV 基线，并围绕 2025 年以来频域增强、双域融合、深度先验、组合损失等方向开展 **可插拔消融研究**，形成可写进大创/竞赛/论文的完整实验闭环。

### 1.2 研究意义

- **理论意义**：探索「强基线 + 轻量插件」范式，在冻结主干条件下验证新机制是否带来稳定增益，为 RWKV 视觉复原提供可复现实验范式。
- **应用意义**：去雾结果可直接服务后续检测/分割（如 EnergySnake 脊柱 MRI 管线中的对比度增强环节），具备跨任务迁移潜力。
- **教学与双创意义**：形成开源仓库、中期数据、对比图与报告，便于答辩展示与后续国创/挑战杯材料复用。

## 三、技术路线

### 3.1 总体路线

```
有雾图像数据集
    ↓
Vision-RWKV V1 基线训练（128×128，MSE，50 epoch）
    ↓
冻结 V1 骨干 + 四方向轻量插件（A/B/C/D）
    ↓
模板试训（512 张）→ 数值/人工校验 → 全量训练（约 1.4 万张）
    ↓
主观对比 + 客观指标（PSNR/SSIM）→ 中期报告与开源发布
```

### 3.2 四方向插件设计

| 方向 | 文献依据 | 插件实现 | 参数量级 |
|------|----------|----------|----------|
| A | Fourier-RWKV (arXiv:2512.08161) | FourierMix2D 频域门控残差 | ~1k |
| B | 双域去雾综述 | 高频 FFT + depthwise 精炼 | ~2k |
| C | UDPNet 深度先验 | 轻量深度门控 | ~1k |
| D | 组合损失文献 | 轻量空间残差头 | ~2k |

### 3.3 训练策略创新

- **V1 锚定损失**：`L = MSE(out,clear) + w_anchor·MSE(out,V1)`，防止插件破坏基线。
- **有界 scale**：sigmoid 限制插件贡献上限，避免训练发散。
- **零初始化**：B/C/D 输出层零初始化，训练起点等同 V1。
- **两阶段训练**：先小样本模板试训，再全量训练，降低「训错再重来」成本。

## 四、阶段性研究进展

### 4.1 基线 V1 复现与验证

- 结构：`hidden_dim=32`，`num_blocks=2`，全局残差 `sigmoid(conv(feat)+x)`。
- 数据：约 13,990 对 hazy/clear，训练分辨率 **128×128**。
- 权重：`rwkv_dehaze_epoch_50.pth`。
- 指标（500 张 hold-out）：**PSNR 20.66 dB，SSIM 0.827**。

### 4.2 V2 整网重训探索（已终止）

曾尝试 256×256 整网重训（`model_rwkv_v2`），快速消融与 50 epoch 公平重训均出现 **灰图、对比度塌缩、频域 NaN** 等问题。结论：整网重训不适合作为中期主结果，改为 **冻结 V1 + 插件**。

### 4.3 插件消融主线（当前成果）

完成 A/B/C/D 模板试训与 B/C/D 全量训练（A 采用 ep0 近 V1 策略）。主观上 B/C/D 中期检查样例 **可接受**；客观指标显示 A/C 与 V1 最接近，B/D 在部分 hold-out 上 PSNR 偏低，已列入后续 epoch 扫描计划。

### 4.4 工程化与开源

- GitHub：https://github.com/FBB123571/Restore-RWKV
- 脚本：`train_plugin_template.sh`、`train_plugin_full.sh`、`eval_plugins_metrics.py`
- 文档：`PLUGIN_TRAIN_WORKFLOW.md`、本中期报告

## 五、实验结果与分析

### 5.1 客观指标（500 张 hold-out，128px）

| 模型 | PSNR↑ | SSIM↑ | ΔPSNR vs V1 |
|------|-------|-------|-------------|
| 有雾输入 | 13.88 | 0.702 | — |
| **V1 基线** | **20.66** | **0.827** | — |
| Plg-A (ep0) | 20.62 | 0.826 | −0.04 |
| Plg-B (full) | 16.68 | 0.697 | −3.98 |
| Plg-C (full) | 20.14 | 0.817 | −0.52 |
| Plg-D (full) | 15.73 | 0.728 | −4.92 |

### 5.2 结果分析

1. **A/C 与 V1 数值接近**：符合「保守插件 + 强锚定」设计目标，适合作为稳定可交付版本。
2. **B 主观尚可但 hold-out PSNR 偏低**：可能与 epoch 14 在难例上过修有关，需做 epoch 扫描。
3. **D 全量后指标下降**：说明仅特征精炼仍可能漂移，需更强约束或早停。
4. **肉眼与 PSNR 不完全一致**：中期以多指标 + 难例子集联合评价，避免小样本误判。

## 六、项目创新点

1. **冻结强基线的可插拔消融范式**：不改动 `model_rwkv.py` 与 V1 权重，保证对比公平与工程可回退。
2. **模板—全量两阶段训练流程**：先 512 张试训再全量，显著降低消融「训错」风险（大创项目可复用）。
3. **四方向统一评测脚本**：同一 hold-out 集、同一配对规则，输出 CSV 便于写报告/论文。
4. **线性复杂度主干**：相较重型 Transformer 去雾网络，更利于后续嵌入式/实时方向拓展。

## 七、存在问题与改进措施

| 问题 | 原因 | 改进措施 |
|------|------|----------|
| 插件未显著超越 V1 | 锚定过强、scale 过小 | 单方向放宽 scale，val 集早停 |
